aide privacy policy

Last updated: 12 October 2026.

aide is used only by its owner, Derick Wells. No one else can sign in to it.

What it accesses

With the owner's permission, aide reads the owner's Gmail, Google Calendar and Google Tasks. It creates, changes or sends something only when the owner confirms that specific action.

How the data is used

The data is used only to answer the owner's own questions and carry out the owner's own requests. It is not sold, shared, or used for advertising.

Where it is kept

Access tokens are stored encrypted on the owner's own computer. Messages are processed to produce answers and are not kept in any separate database.

Google user data

aide's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time from Google Account permissions.
